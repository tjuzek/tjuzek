### Key projects

- **[ai-34-languages](https://github.com/tjuzek/ai-34-languages)**: pipeline and interactive
  explorer for AI-overused words across 34 languages. Powers
  [aiwordexplorer.com](https://www.aiwordexplorer.com/).
  Paper: *AI-Associated Lexical Shifts Across 34 Languages* ([arXiv:2605.25358](https://arxiv.org/abs/2605.25358)).
- **[delve](https://github.com/tjuzek/delve)**: code for *Why Does ChatGPT "Delve" So Much?*
  (COLING 2025, [arXiv:2412.11385](https://arxiv.org/abs/2412.11385)).
- **[lhf](https://github.com/tjuzek/lhf)**: code for *Word Overuse and Alignment in LLMs: The
  Influence of Learning from Human Feedback* (BIAS 2025 @ ECML-PKDD, [arXiv:2508.01930](https://arxiv.org/abs/2508.01930)).
- **[sad](https://github.com/tjuzek/sad)**: the Syntactic Acceptability Dataset, with the
  accompanying paper and rating-website code.
